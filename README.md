# HealthConnect Database System

A healthcare database design and implementation project created for COSC 4385 Database Management Concepts.

This project models a healthcare network system with facilities, providers, patients, appointments, memberships, insurance, billing records, wellness programs, and community engagement features.

## Project Contents

- Phase 1: EER design and assumptions
- Phase 2: Relational schema and normalization
- Phase 3: SQL implementation
- Final Report: Complete database documentation

## Technologies Used

- SQL
- MySQL
- EER Modeling
- Relational Database Design
- Normalization
- Database Implementation

## Key Features

- Designed an EER model for a healthcare database system
- Converted the EER model into relational schemas
- Normalized database tables
- Created SQL table definitions
- Inserted sample healthcare data
- Built SQL views and analytical queries
- Documented assumptions, constraints, and system requirements
